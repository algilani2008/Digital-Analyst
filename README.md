# المحلل الرقمي · The Digital Analyst

موقع خدمات تحليل البيانات وذكاء الأعمال، ومعها تصميم الأنظمة والمواقع ودراسات الجدوى، للسوق السعودي.

**الموقع:** https://algilani2008.github.io/Digital-Analyst/

## وش في الموقع
- **وش أحتاج؟** أربع أسئلة تطلع للعميل خطة تحليل مقترحة.
- **أدوات مجانية تشتغل على ملف العميل داخل متصفحه:** لوحة مبيعات، مصادر الزيارات، طلبات الصيانة.
- **نماذج أنظمة:** العملاء والمبيعات، المخزون، الموارد البشرية.
- **حاسبة جدوى مبدئية لخمس سنوات** بالرسوم الحكومية السعودية، ومحاكي خصومات، وخمس حالات توضيحية.
- الباقات، الأسئلة الشائعة، سياسة الخصوصية، ونموذج طلب مشروع.

## الدخول
| الصفحة | لمين | الرابط |
|---|---|---|
| مركز التحكم | مالك الموقع: العملاء، الباقات، المشاريع، الطلبات، التقارير، الفواتير | `login.html?as=owner` ثم `admin/` |
| بوابة العملاء | العميل: باقته، أدواته بحدود الباقة، مراحل مشروعه، طلباته، تقاريره، فواتيره | `login.html` ثم `portal/` |

**الوضع الحالي تجريبي:** الحسابات والبيانات تنحفظ في متصفح الجهاز فقط. الانتقال لقاعدة بيانات حقيقية على Hostinger موضح في `server/API.md`، وقاعدة البيانات في `server/schema.sql`.

## الخصوصية
الملفات اللي يرفعها الزائر تنقرى داخل متصفحه، وما تنرسل لأي خادم.

## التعديل
- **بيانات التواصل:** في `index.html` ابحث عن `var CONTACT=` واكتب رقم الواتساب بالصيغة الدولية (مثل 9665XXXXXXXX) والإيميل.
- **الرسوم الحكومية في الحاسبة:** كلها في `var GOV=` مع تاريخ آخر تحديث.

## اللغات

العربية هي الأصل، والإنجليزية طبقة ترجمة: `assets/i18n.js` (المحرك وأنماط الجمل اللي فيها أرقام) و`assets/i18n-en.js` (القاموس). زر اللغة في أعلى الصفحة، أو `?lang=en`. أي نص جديد بالعربي ينضاف له مقابل في القاموس، وإلا يبقى عربي في النسخة الإنجليزية. أسماء المدن والأحياء وصفحات الدخول ومركز التحكم وبوابة العملاء عربية فقط للحين.

## الأمان

- **سياسة أمان المحتوى (CSP)** في كل الصفحات: السكربتات من نفس الموقع فقط (بدون سكربتات داخل الصفحة وبدون CDN)، والاتصال بنفس الموقع فقط، والصور من الموقع وخرائط Esri وOpenStreetMap.
- **المكتبات محلية:** SheetJS وLeaflet في `assets/vendor/`، فما يتحمل أي كود من طرف ثالث.
- **بيانات المستخدم ما تنحط كـ HTML:** ملفات Excel والإدخال اليدوي تمر على `esc()` قبل العرض.
- **كلمات المرور في الوضع التجريبي:** PBKDF2-SHA256 بـ 210 ألف دورة، محفوظة في المتصفح فقط. هذي حماية للنسخة التجريبية، والحماية الفعلية تجي مع خادم Hostinger (`server/API.md`).
- **المفاتيح:** مفاتيح الذكاء الاصطناعي في GitHub Secrets فقط، وخطوات GitHub Actions مثبتة على رقم الإصدار (commit SHA).
- **حدود GitHub Pages:** ما يسمح بترويسات HTTP مثل HSTS وX-Frame-Options وframe-ancestors. تنضبط لما ننتقل لاستضافة تدعمها.
